# ME 3 Deck v2

Re-sized for a 1920 x 1080 slide. Every image is rendered at the pixel box it
will occupy, at 150 dpi, so nothing is scaled down into illegibility.

| File | Pixels | Goes where | % of slide |
|---|---|---|---|
| `diagram.png` | 1800 x 520 | top half of a page | 94 % wide |
| `MCP_Services.png` | 1800 x 520 | top half of another | 94 % wide |
| `Benchmark.png` | 900 x 480 | bottom-right quarter | 47 % wide |
| `latency_chart.png` | 880 x 460 | beside the benchmark table | 46 % wide |
| `prompt.md` | 1,207 chars | bottom-left quarter | 1/4 page at 9 pt |
| `prompt_full.md` | 12,010 chars | the record, not a slide | — |

Smallest type in any image is 7.6 pt at 150 dpi, about 16 px tall, and after the
slide's 5 % margin that stays at ~15 px. The v1 images were 2535 x 3606 px for a
quarter-page table; pasted and shrunk, their 8 pt text landed at ~4 px.

## Nothing here is typed by hand

| Generated by | Produces |
|---|---|
| `bench/gen_deck_v2.py` | all four PNGs, from `bench/results/full-2026-11-18/` and `config.py` |
| `bench/gen_prompt_v2.py` | `prompt.md`, `prompt_full.md`, read out of `config.py` |
| `bench/mock_slides.py` | `slides/` — the images composited into 1920 x 1080 pages |
| `bench/check_layout.py` | no-overlap, no-off-canvas check on every label |
| `bench/verify_figures.py` | re-derives every number and diffs it against the prose |

Run the last two before shipping:

```bash
.venv/bin/python bench/check_layout.py        # geometry
.venv/bin/python bench/verify_figures.py --check   # numbers
```

`slides/` is a fit check, not a deliverable. It exists so the claim "this fits a
half page" is a measurement rather than an assertion.
