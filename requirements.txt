# Full-Duplex Voice AI Agent (v4) -- dependencies
#
# Platform: Raspberry Pi 5 8GB, aarch64 (ARM64), no GPU, Python 3.12.
#
# System packages (install with sudo -- NOT in this file):
#   sudo apt-get install -y python3-venv portaudio19-dev libasound2-dev
#
#   portaudio19-dev + libasound2-dev are needed so PyAudio's bundled
#   PortAudio links the ALSA backend (modern RPi OS is ALSA-only; without
#   libasound2-dev the build is OSS-only and sees 0 audio devices).
#
# NOTE on reuse: this Pi already has a working venv (see ENVIRONMENT.md) with
# the heavy artifacts (faster-whisper, sherpa-onnx, Piper TTS, the Zipformer
# ASR model). Point the agent at those rather than re-downloading ~2.3 GB.
#
# NOTE on the mic: the USB capture card only accepts 48 kHz for capture
# (16/8/32 kHz fail). The agent captures at 48 kHz and resamples to 16 kHz
# for VAD/ASR. See config.py / audio_io.py.
#
# --- NO TORCH in this project ---
# torch is deliberately NOT installed. It is heavy (~1.5-2 GB) and is NOT
# needed for VAD: Pipecat's SileroVADAnalyzer loads the Silero ONNX model
# through onnxruntime (CPUExecutionProvider), not torch. (The `silero-vad`
# PyPI package is a separate TorchAudio wrapper that Pipecat does not use.)
# So we get Silero VAD with zero torch cost -- just `onnxruntime` below.

# --- Core agent harness (Pipecat) + the extras we use ---
# pipecat-ai[mcp]     : MCP support (the agent talks to its own MCP servers)
# pipecat-ai[webrtc]  : WebRTC audio transport (aiortc)
# pipecat-ai[piper]   : Piper TTS (local, low latency)
# pipecat-ai[openai]  : OpenAI-compatible LLM client
# pipecat-ai[whisper] : faster-whisper (local ASR)
# NOTE: the `silero` extra is intentionally omitted -- it installs the
#       `silero-vad` TorchAudio wrapper (hard-requires torch). Pipecat's own
#       SileroVADAnalyzer uses onnxruntime instead, so we add onnxruntime
#       directly below and keep torch out of the dependency graph.
pipecat-ai[mcp,webrtc,piper,openai,whisper]

# --- MCP framework (the ASR + TTS MCP servers are built on FastMCP) ---
mcp>=2.0.0
fastmcp>=2.0.0

# --- VAD (torch-free) ---
onnxruntime>=1.17.0          # primary VAD -- SileroVADAnalyzer runs the Silero
                             # ONNX model on CPU via onnxruntime (no torch)
webrtcvad>=2.0.10            # lightweight fallback VAD -- zero dependencies
setuptools<81                # for pkg_resources (webrtcvad build)
